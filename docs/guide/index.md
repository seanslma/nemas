# Welcome to nemas

NEMAS: National Electricity Market Analytics System.

This user guide is intended to walk you through getting started, providing examples, and explaining core concepts.

## Structure

User Guide: Conceptual overviews, installation steps, and tutorials.

API Reference: Detailed, auto-generated documentation for every function and class (powered by Sphinx).

Check out the Tutorial to see how nemas works!


## NEMWEB data

- Reports/CURRENT/Daily_Reports: last 60 days (exclude today). Yesterday's data published at 4am.
- Reports/ARCHIVE/Daily_Reports: last 13 months (exclude current month). One month delay: data before previous month will be published on the first day of each month.
